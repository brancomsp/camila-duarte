# CAMILA DUARTE — Personal Stylist Portfolio

## Tecnologias
- Next.js
- TailwindCSS
- TypeScript

---

# Instalação local

```bash
npm install
npm run dev
```

Abrir:
http://localhost:3000

---

# Build produção

```bash
npm run build
npm start
```
